DecodeManager Test Pattern

A reusable pattern for scheduler policy tests that do not need a model server.

What To Test

  1. Empty manager behavior.
  2. Stable batch ordering.
  3. Filtering of requests that cannot decode.
  4. Abort and remove semantics.
  5. Capacity estimates such as inflight_tokens.

Helper Shape

class DummyCacheHandle(BaseCacheHandle):
    def get_matched_indices(self):
        return torch.empty(0, dtype=torch.int32)

def make_req(uid, output_len=1, prompt_len=1):
    return Req(
        input_ids=torch.arange(prompt_len, dtype=torch.int32),
        table_idx=uid,
        cached_len=0,
        output_len=output_len,
        uid=uid,
        sampling_params=SamplingParams(max_tokens=output_len),
        cache_handle=DummyCacheHandle(cached_len=0),
    )

The helper builds real Req objects while replacing the cache handle with a harmless stub because DecodeManager does not inspect cache contents.

Command

python -m pytest tests/core/test_decode_manager.py -q

If the active environment does not have the repo's dev test plugins, bypass configured addopts while doing a quick local check: 

python -m pytest -q -o addopts='' tests/core/test_decode_manager.py
