CacheManager Test Pattern

A reusable pattern for testing scheduler-owned KV-page allocation.

What To Test

  1. Cached prefix page-table entries are preserved.
  2. Fresh physical pages are written only for the uncached page range.
  3. free_slots shrinks by the expected page count.
  4. Remaining free slots stay page-aligned.
  5. Multiple request rows receive non-overlapping physical locations.

Helper Shape

manager = CacheManager(
    num_pages=8,
    page_size=4,
    page_table=page_table,
    type="naive",
)

Use type="naive" when testing physical allocation only. That avoids radix-cache setup and keeps the test focused on allocate_paged.

Core Formula

first_page = ceil(cached_len / page_size)
last_page = ceil(device_len / page_size)
needed_pages = last_page - first_page

allocate_paged writes token-level physical locations for pages in the half-open range [first_page, last_page).

Command

python -m pytest tests/core/test_cache_manager_allocate_paged.py -q

If dev plugins are missing, do a quick local check with: 

python -m pytest -q -o addopts='' tests/core/test_cache_manager_allocate_paged.py
