Run and Debug Checklist

A compact startup checklist for Mini-SGLang.

Preflight

python --version
uv --version
nvidia-smi
python -c 'import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.device_count())'

If nvidia-smi or torch.cuda.is_available() fails, do not debug scheduler logic yet. Fix GPU visibility, CUDA, container runtime, or Python environment first.

Install

uv venv --python=3.12
source .venv/bin/activate
uv pip install -e .

Mini-SGLang depends on CUDA-facing packages from pyproject.toml, including PyTorch, FlashInfer, SGL kernels, TVM FFI, and related runtime packages.

Start Server

python -m minisgl --model "Qwen/Qwen3-0.6B"

The default server address is 127.0.0.1:1919. Use --host and --port to change it.

Expected Processes

  1. One frontend API server process.
  2. One scheduler process per tensor-parallel rank.
  3. One detokenizer worker.
  4. Zero or more tokenizer workers; --num-tokenizer 0 shares tokenizer and detokenizer.

Layer Triage

Environment

Missing torch, no CUDA device, blocked NVML, missing compiled kernel package.

Model loading

Bad model path, Hugging Face download failure, missing config, unsupported architecture.

Process startup

No "ready" acknowledgements from scheduler/tokenizer/detokenizer.

Frontend

Port conflict, wrong host, request schema error, client disconnect.

Scheduler

Requests received but no progress through prefill/decode, cache allocation failure, capacity issue.

Engine

CUDA OOM, attention backend failure, graph capture failure, tensor-parallel communication issue.

Useful Flags

--dummy-weight

Use generated weights for testing startup without real model weights.

--cache-type naive

Disable radix prefix reuse to isolate cache-index behavior.

--cuda-graph-max-bs 0

Disable CUDA graph capture when debugging graph-specific failures.

--max-prefill-length

Change chunked prefill size when debugging long-prompt admission.

--page-size

Change cache page granularity; test page-alignment behavior carefully.

--tp-size

Set tensor-parallel rank count. Start with one GPU before debugging multi-rank issues.
